# RENEW V1 Mobile QA Checklist

## Device Tests
- [ ] 320px width (small Android)
- [ ] 360px width
- [ ] 480px width
- [ ] 720px width (large phone)
- [ ] 1024x768 (Tablet)

## Player Journey (No Keyboard)
- [ ] Can tap "INSPECT" to start.
- [ ] Can tap "ACQUIRE" to buy the warehouse.
- [ ] Can tap "RESTORE" repeatedly until "Operational".
- [ ] Can tap "OPEN BUSINESS" to launch RENEW Goods.
- [ ] Can tap "HIRE" to add employees.
- [ ] Can tap "BUY INPUTS" to stock resources.
- [ ] Can tap "PRODUCE" to create finished goods.
- [ ] Can tap "PRICE" to adjust selling price.
- [ ] Can tap "END DAY" to advance time.
- [ ] Day-end summary popup appears with profit/loss.

## UI Responsiveness
- [ ] All buttons are at least 44x44 points.
- [ ] The feedback panel slides in and fades out correctly.
- [ ] Scrolling in the action grid works smoothly.
- [ ] The "WORLD" tab shows regions and competition clearly.

## Performance
- [ ] FPS stays above 30 on low-end device.
- [ ] Memory usage does not spike after 10 minutes of play.
- [ ] Save/Load completes in under 1 second.

## Economy
- [ ] First day profit is positive if you produced goods.
- [ ] Loan repayment doesn't bankrupt you immediately.
- [ ] Competitor prices react to your changes.
- [ ] Contract revenue is visible in the day summary.
