RESTORA • PLAYER PRIVACY

Privacy Policy

Effective 2 October 2026

Current production posture

RESTORA is designed to work without creating an account. The current release configuration keeps gameplay state, save files, accessibility preferences and audio/theme settings on your device or in your browser's local storage.

No account requiredNo in-game analyticsAds disabledPurchases disabled

Information RESTORA handles

The game creates local gameplay data such as progress, company state, save slots, preferences and achievement history. This information is used to run the simulation and restore your session. In the current release, RESTORA does not operate its own server that receives this gameplay data.

Network access and tracking

The current Android production configuration does not request Internet access and does not include a network analytics implementation. RESTORA does not sell personal information or use gameplay data for cross-app advertising in this configuration.

Web version

When you play the web build, your browser and the hosting platform may process ordinary technical request data such as IP address, user agent and request timing to deliver the site. RESTORA's game code does not add its own analytics layer in the current release. Local game progress may be stored by your browser.

Optional ads or purchases

The codebase contains support for optional rewarded advertising and premium entitlements, but these features are disabled in the current production configuration. If a future release enables Google Play Billing, advertising, consent tooling or another third-party service, this policy and the applicable store disclosures will be updated before that configuration is released.

Deleting local data

You can remove locally stored RESTORA data by clearing the app's storage, uninstalling the app, or clearing site data for the web version. These actions can permanently erase saves unless you have another copy.

Children

RESTORA does not knowingly ask players to provide personal information in the game. If the data practices change, the policy and store age/data disclosures will be updated accordingly.

Changes to this policy

Material changes will be reflected on this page with a new effective date. The policy will be reviewed whenever networking, analytics, advertising, purchases or account features are added or changed.

Contact

Privacy questions and reports can be submitted through the project's public support tracker: RESTORA support on GitHub.
