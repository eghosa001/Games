# RENEW Prototype 03

Prototype 03 adds the foundations for the full economic strategy layer.

## Systems added
- Resource market: materials, packaging and fuel with changing prices and stock.
- Suppliers: reliability, markup and resource specialization.
- Rival corporations: The Giant, The Specialist and The Network.
- Relationship and alliance progression.
- Expansion opportunities: retail, factory and cold storage properties.
- Local save/load foundation using `user://renew_save.json`.

## Design direction
The player should eventually have to choose between vertical integration, supplier dependence, alliances, aggressive pricing and reinvestment. No single strategy should dominate.

## Next integration target
Wire these systems into the main gameplay screen, then add production chains, employees, contracts, events and a multi-business empire view.
